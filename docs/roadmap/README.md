3. **طراحی**: صفحات، جریان کار، مدل داده (ERD)، معماری

5. **کیفیت**: تست واحد و یکپارچه، اعتبارسنجی ورودی، مدیریت خطا
6. **آماده‌سازی استقرار**: Docker، متغیرهای محیطی، README با دستور اجرا
7. **دمو**: اسکرین‌شات، ویدئوی دمو، داده نمونه (seed)

## نظر کارشناسی: آنلاین یا آفلاین؟
- **آنلاین (اکثریت)**: چون چند کاربر باید هم‌زمان روی داده یکسان کار کنند. CRM، فاکتور، سفارش، اشتراک، ATS، مرخصی، پرتال، Wiki، تیکت، فرم، اسناد، اتوماسیون ایمیل و BI باید سرور مرکزی داشته باشند.
- **آفلاین‌پذیر (هیبرید)**: جایی که اتصال ناپایدار یا محیط فیزیکی مهم است: **حضور و غیاب** (کیوسک ورود)، **انبار** (اسکنر در انبار)، **ردیاب زمان** و **هزینه‌ها** (ثبت در موقعیت بدون اینترنت و همگام‌سازی بعدی). تکنیک: PWA + IndexedDB + صف همگام‌سازی.
- **آفلاین کامل (دسکتاپ)**: در این فهرست فقط مورد خاصی لازم نیست. پیشنهاد صریح من: همه را وب بساز و فقط ۲–۳ مورد را PWA آفلاین‌پذیر کن. آفلاین کامل برای رزومه ارزش کمتری دارد و نگهداری آن سخت‌تر است.

## نکات جاافتاده (پیشنهاد اضافه)
اگر خواستی فهرست را گسترش بدی، این موارد هم برای سازمان‌ها خیلی کاربردی‌اند:
- **سیستم صندوق فروشگاه (POS)**: حتماً آفلاین‌پذیر، پرکاربرد برای خرده‌فروشی
- **مدیریت دارایی‌ها (Asset Management)**: ثبت تجهیزات، تخصیص به کارمند، استهلاک
- **مدیریت قرارداد و امضای الکترونیک**: چرخه تایید و نسخه‌بندی قرارداد
- **پیام‌رسانی داخلی سازمان**: کانال‌ها و پیام مستقیم (سنگین‌تر، برای مرحله آخر)

# پروژه ۰۱: CRM ساده

## مشخصات کلی
- **مسئله**: فروشنده‌ها سرنخ‌ها و مشتری‌ها را در اکسل و واتساپ نگه می‌دارند و پیگیری گم می‌شود.
- **کاربران**: مدیر فروش، فروشنده، پشتیبان
- **حالت**: آنلاین (وب)

## ابعاد ویدئوی معرفی (پرزنت)
- **نسبت تصویر**: 16:9 — **وضوح**: 1920×1080 — **نرخ فریم**: 30 fps
- **مدت**: حدود ۸ تا ۱۰ دقیقه
- **زبان**: فارسی با زیرنویس فارسی (RTL)، فونت: Vazirmatn
- **سبک**: اسلاید + نمودار + موکاپ UI، بدون ویدئوی شلوغ
- **صدا**: گوینده مصنوعی یا صدای شما (نیاز به انتخاب صدا)
- **فرمت خروجی**: MP4 (H.264) + فایل اسلایدها (PDF)

### ویژگی‌های MVP (نسخه اول)
- ورود و نقش‌ها (مدیر / فروشنده)
- CRUD مشتری و تماس‌ها
- سرنخ با مراحل: جدید → در تماس → پیشنهاد → برنده / بازنده
- پایپ‌لاین (Kanban) با جابه‌جایی کارت
- یادآوری پیگیری (تاریخ بعدی)
- داشبورد: تعداد سرنخ، نرخ تبدیل، فروش ماه
- جستجو و فیلتر

### پیشنهاد فناوری (ساده و قابل استقرار)
- فرانت: React + Vite یا Next.js
- بک‌اند: Node.js (Express/Fastify) یا Next.js API
- دیتابیس: PostgreSQL + Prisma
- احراز هویت: JWT یا NextAuth
- استقرار: Docker Compose
