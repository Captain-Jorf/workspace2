# ۰۶ — یکپارچه‌سازی با Clarius L20 (دستگاه موجود شما)

> به‌روزرسانی ۲۰۲۶-۱۰-۰۱: تیم اعلام کرد دستگاه اولتراسوند پروژه **Clarius 20** است (به‌احتمال زیاد **L20 HD3**).
> این فایل جایگزین بخش «ساخت پروب» در فایل‌های ۰۳ و ۰۵ می‌شود.

---

## ۱. چرا این انتخاب درست است

**L20 HD3 دقیقاً همان دستگاهی است که ادبیات بالینی این حوزه با آن کار کرده.** یعنی:

| مطالعه | دستگاه |
|---|---|
| تکنیک صرفه‌جویی زمان، ۵۰۳ بیمار / ۱,۱۰۹ سی‌سی، صفر عارضه‌ی عروقی (ASJ Open Forum 2025) | **Clarius L20** (نویسنده صریحاً «حساسیت Clarius L20 می‌تواند محدودیت باشد» را به‌عنوان محدودیت مطالعه ذکر می‌کند) |
| نقشه‌برداری شریان فاسیال در مندیبل و NLF (Damitz، عمق ۳٫۴±۰٫۶ میلی‌متر) | **Clarius HD (8–20 MHz) L20** |
| کلینیک‌های زیبایی در آمریکا/استرالیا/کانادا | Clarius به‌طور فعال بازاریابی می‌کند: «designed specifically for aesthetics» |

**پیامد:** داده‌ی شما با ادبیات قابل مقایسه است، مدل AI روی همان دستگاهی آموزش می‌بیند که کلینیک هدف می‌خرد، و مقاله‌پذیری بالا می‌رود. **و مهم‌تر: لازم نیست پروب بسازید** — که در فایل ۰۳ بزرگ‌ترین ریسک سخت‌افزاری بود.

## ۲. مشخصات دقیق دستگاه (برای طراحی پروتکل)

| مشخصه | مقدار | پیامد برای MURA |
|---|---|---|
| فرکانس | **۸–۲۰ MHz** | برای عروق ۰٫۸–۱٫۸ میلی‌متر در عمق ۲–۴ میلی‌متر مناسب. دک شما «۱۰–۱۸» گفته بود — بازه‌ی واقعی دستگاه گسترده‌تر است؛ در دک اصلاح شود |
| حداکثر عمق | **۴ سانتی‌متر** | کل صورت پوشش داده می‌شود |
| **میدان دید (FOV)** | **۲۵ میلی‌متر** | ⚠️ **محدودیت مهم.** هر فریم فقط ۲۵ میلی‌متر عرض دارد → برای نقشه‌ی کامل یک ناحیه (مثلاً کل NLF یا کل پیشانی) به **چندین پاس جارویی** نیاز دارید. این یعنی بازسازی سه‌بعدی اجتناب‌ناپذیر است و خطای تجمعی ثبت وارد کار می‌شود |
| ابعاد / وزن | ۱۴۷ × ۷۶ × ۳۲ میلی‌متر / **۲۹۰ گرم**، بدنه منیزیم | عرض ۷۶ میلی‌متر برای نواحی **پری‌اوربیتال و پری‌اورال** بزرگ است. در پروتکل، برای این نواحی زاویه‌ی خاص و پروب‌گیری متفاوت تعریف کنید |
| عناصر / بیم‌فورمر | ۱۹۲ عنصر پیزو، ۸ بیم‌فورمر، تا ۳۰ فریم/ثانیه (طبق اعلام نمایندگی) | ۳۰ fps برای جاروب دستی کافی است؛ برای ردیابی حرکت سریع نه |
| مدهای تصویر | B-Mode، M-Mode، **Color/Power Doppler**، Pulsed Wave (با عضویت)، **Needle Enhance**، Split Mode، Elastography (با عضویت) | **Needle Enhance** = قابلیت داخلی برای دیدن سوزن → برای فاز «هدایت زنده» مفید است. **Power Doppler** برای رگ‌های ریز حیاتی است |
| Clarius Intelligence (AI داخلی) | Voice Controls، **T-Mode™ for Aesthetics**، **Auto Vessel Depth AI**، Auto Gain | ⚠️ **هشدار رقابتی جدی** — بخش ۵ |
| باتری | اسکن ~۶۰ دقیقه (دفترچه‌ی HD3 می‌گوید ~۴۵ دقیقه استفاده‌ی معمول)، شارژ ~۹۰ دقیقه، استندبای ~۷ روز | برای یک روز کلینیک شلوغ **باتری اضافه** لازم دارید |
| **حداکثر زمان معاینه‌ی توصیه‌شده** | **۲۰ دقیقه** | ⚠️ **محدودیت طراحی.** کل پروتکل اسکن شما باید زیر ۲۰ دقیقه باشد. گزارش‌هایی از **گرم شدن دستگاه** در استفاده‌ی طولانی وجود دارد |
| خروجی داده | Wireless 802.11abgn، Bluetooth، **DICOM**، Cloud | مسیرهای جایگزین برای جمع‌آوری داده |
| پلتفرم | **iOS 16+ / Android 13+**، Wi-Fi 802.11n (5GHz)، BLE 4.0+ | اپ شما باید روی همین پلتفرم‌ها بنشیند |
| قیمت | **$۵,۳۹۵ / €۴,۸۴۰** (اسکنر تنها) یا €۵,۳۹۵ با عضویت؛ عضویت سالانه **$۵۹۵–۶۹۵**؛ «Advanced Aesthetics Package» جداگانه ~**$۲,۵۰۰** | این عدد، ادعای «کیت ۵,۰۰۰ یورویی با حاشیۀ ۶۵–۷۰٪» را باطل می‌کند |

## ۳. اکوسیستم توسعه‌دهنده‌ی Clarius — مهم‌ترین یافته

Clarius یک **پورتال توسعه‌دهنده‌ی رسمی** دارد: `github.com/clariusdev` (لایسنس BSD-3-Clause) و یک «Clarius Marketplace» برای AI ثالث. پنج مسیر:

| API | چه می‌دهد | پیش‌نیاز | مناسب MURA؟ |
|---|---|---|---|
| **Cast** | استریم **بلادرنگ** تصویر و داده از پروب **همزمان با اجرای اپ Clarius**. طبق مستندات: «ساده‌ترین راه برای گرفتن تصویر زنده و داده‌ی خام برای پژوهش». نسخه‌ی عمومی فعلی **v12** | اپ Clarius در حال اجرا و متصل به پروب؛ پروب/موبایل/کامپیوتر روی **یک شبکه‌ی وای‌فای**؛ داده‌ی خام فقط در حالت **freeze** قابل گرفتن است مگر RF streaming از اپ فعال شود | ✅ **مسیر MVP شما.** هفته‌ها، نه ماه‌ها |
| **Research** | فرمت‌های داده‌ی خام: **RF / channel RF / IQ / envelope / greyscale / Doppler** + readerها + ابزارهای پژوهشی داخل اپ + مرجع پارامترهای سطح پایین. Python | لایسنس پژوهشی | ✅ برای ساخت دیتاست و مدل |
| **IMU** ⭐ | **IMU نه‌درجه‌آزادی یکپارچه در خود پروب**: دسترسی به داده، کالیبراسیون، و **کواترنیون جهت‌گیری** | — | ✅✅ **کلید قفل «دوقلوی دیجیتال».** جهت‌گیری پروب را بدون ردیاب خارجی می‌دهد → بخشی از بازسازی freehand 3D حل می‌شود |
| **Solum** | API برای ساخت اپ **standalone** که **مستقیماً** به پروب وصل می‌شود، **بدون نیاز به اپ Clarius**. روی Windows/Linux/macOS/iOS/Android | ⚠️ **«باید شریک تجاری باشید و به‌صورت فصلی تعداد عمده دستگاه بخرید» + لایسنس «oem» برای هر پروب** | 🎯 محصول نهایی، ولی **در مرحله‌ی pre-seed در دسترس نیست** |
| **Cloud** | ارسال معاینات تکمیل‌شده از Clarius Cloud به پلتفرم‌های دیگر (مرور بالینی، **AI ابری**، گزارش‌دهی، EMR) | — | ✅ برای نسخه‌ی ابری/غیربلادرنگ |

**پلتفرم پژوهشی Clarius رسماً این‌ها را تبلیغ می‌کند:** دسترسی به داده‌ی خام (RF، channel RF، IQ، greyscale، Doppler)، **«موقعیت‌یابی سه‌بعدی: IMU نه‌درجه‌آزادی برای ردیابی حرکت و برچسب‌گذاری فضایی»**، Cast API با کنترل پارامترها، ابزار توسعه در Python/MATLAB/C/C++/Java/Swift، مستندات فرمت **YAML** برای متادیتای RF و تصویر، پشتیبانی Windows/Linux/macOS/Android/iOS، و مدهای اختیاری CEUS و **Photoacoustics**.

> **نتیجه:** جمله‌ی «Clarius می‌گوید Cast API از استریم بلادرنگ داده و کنترل سطح پایین برای یکپارچه‌سازی با **پایپلاین‌های ML سفارشی** پشتیبانی می‌کند» — یعنی مسیر فنی شما رسماً پشتیبانی‌شده است. این را در دک بنویسید؛ اعتبار فنی می‌آورد.

### ابزارهای آماده (چرخ را از اول نسازید)

| ابزار | کاربرد |
|---|---|
| **FAST** (`fast-imaging.github.io/clarius-module.html`) | آبجکت `ClariusStreamer` برای استریم B-mode و Doppler بلادرنگ. از Clarius Listen API استفاده می‌کند و **نیاز به research license** دارد. در اپ Clarius باید زیر Clarius Cast گزینه‌ی **«Research (5828)»** انتخاب شود، سپس به access point وای‌فای پروب وصل شوید |
| **3D Slicer + SlicerIGT + PLUS** | کالیبراسیون پروب، ثبت، بازسازی freehand 3D، ناوبری — استاندارد پژوهشی |
| `clariusdev/research` (Python) | خواندن و پردازش داده‌ی خام |
| `clariusdev/app` | **APK اندروید اپ Clarius برای sideload** — «برای محیط‌هایی که از Google Play استفاده نمی‌شود». برای شرایط ایران مستقیماً کاربرد دارد |
| ⚠️ `Mobile API` | **منسوخ شده** (deprecated و بدون نگهداری). سراغش نروید؛ از Cast یا Solum استفاده کنید |

## ۴. معماری به‌روزشده (لایه‌ی ۱ بازطراحی شد)

```
┌──────────────────────────────────────────────────────────────────────┐
│ لایه‌ی ۱ — تصویربرداری: Clarius L20 (موجود)                          │
│                                                                      │
│  مسیر A (MVP / پژوهش):  Cast API  → اپ Clarius روی تبلت + اپ ما کنارش│
│                         فریم‌های B-mode + Color/Power Doppler زنده    │
│                         + متادیتای YAML (فرکانس، عمق، gain، preset)   │
│  مسیر B (داده‌ی خام):    Research → RF / IQ / envelope (در حالت freeze)│
│  مسیر C (pose پروب):     IMU 9-DOF → کواترنیون جهت‌گیری + کالیبراسیون │
│  مسیر D (آفلاین/بایگانی):DICOM export / Clarius Cloud                │
│  مسیر E (محصول نهایی):   Solum  → اپ standalone بدون اپ Clarius       │
│                         ⚠️ نیازمند شراکت OEM + خرید عمده‌ی فصلی        │
└──────────────────────────────────────────────────────────────────────┘
        ↓                                    ↓
   (لایه‌های ۲ تا ۶ طبق فایل ۰۵)      ردیابی موقعیت پروب:
                                       IMU (جهت) + ARKit VIO (موقعیت بصری)
                                       → ترکیب برای کاهش drift
```

**نکته‌ی فنی مهم درباره‌ی IMU:** IMU **جهت** را خوب می‌دهد ولی **موقعیت** را با drift تجمعی (چون انتگرال شتاب است). پس:
- از IMU برای orientation و برای tag‌گذاری فضایی فریم‌ها استفاده کنید.
- برای position از **ردیابی بصری-اینرسی (ARKit/ARCore)** روی بدنه‌ی پروب استفاده کنید، یا در فاز آزمایشگاهی از **مارکر ArUco** روی پروب.
- کالیبراسیون **پروب-به-ردیاب** (probe calibration) هنوز الزامی است — با فانتوم سوزن/سیم (N-wire یا single-wall) انجام می‌شود و در SlicerIGT آماده است.

## ۵. ⚠️ ریسک پلتفرم: Clarius خودش دارد همان کار را می‌کند

این بخش را جدی بگیرید. Clarius روی **همان دستگاهی که شما خریده‌اید** این‌ها را دارد:

| قابلیت Clarius | چقدر به MURA نزدیک است |
|---|---|
| **T-Mode™ for Aesthetics** | AI سگمنتیشن بلادرنگ لایه‌های صورت (درمیس، چربی، SMAS، عضله) با رنگ/بافت/برچسب. Presets برای Forehead/Temple و Lips. تبلیغ مستقیم: «۱۲ لایه‌ی تمپورال»، «ساختارهای حیاتی اطراف بینی» |
| **Auto Vessel Depth AI** | **AI که عمق رگ را خودکار اندازه می‌گیرد** — یعنی بخشی از خروجی اصلی شما را Clarius همین حالا دارد |
| **Clarius Marketplace** (از ۲۰۲۲) | پلتفرم رسمی برای AI ثالث روی دستگاه‌های Clarius؛ SDK برای یکپارچه‌سازی با اپ Clarius و Clarius Cloud |
| **Clarius Classroom** | کانال آموزش رایگان با KOLهای زیبایی (Roberts، Ravera، Moret) |
| تنها محدودیت Clarius | T-Mode صریحاً «**فقط برای اهداف آموزشی و آموزشی**» است → **ادعای بالینی ندارد** |

### سه سناریوی ممکن و پاسخ شما

| سناریو | احتمال | پاسخ |
|---|---|---|
| Clarius شما را از Cast/Solum قطع می‌کند یا لایسنس نمی‌دهد | متوسط | هسته‌ی AI و ثبت را **دستگاه‌agnostic** بسازید: ورودی از DICOM/ویدیو هم پذیرفته شود. پشتیبانی از Butterfly (Garden SDK)، MindRay، GE Vscan، و TodoPocus از ابتدا در معماری باشد |
| Clarius قابلیت مشابه را با ادعای بالینی عرضه می‌کند | متوسط-بالا | **خندق شما باید رگولاتوری و گردش‌کار باشد، نه فنی**: CE Class IIb، نقشه‌ی سه‌بعدی عروق (نه فقط عمق تک‌نقطه‌ای)، ثبت روی صورت بیمار، خروجی پرونده، و شواهد بالینی منتشرشده. Clarius امروز این‌ها را ندارد |
| Clarius شریک/کانال توزیع شما می‌شود | **بهترین حالت** | همین حالا از مسیر **Marketplace** و درخواست research license وارد گفت‌وگو شوید. یک استارتاپ با داده‌ی اختصاصی صورت + ادعای بالینی، برای Clarius جذاب است چون T-Modeشان ادعای بالینی ندارد |

> **توصیه‌ی صریح:** درخواست **research license / Cast access** را همین هفته بفرستید. این درخواست هم پیش‌نیاز فنی شماست و هم بهانه‌ی طبیعی برای باز کردن گفت‌وگو با Clarius قبل از اینکه رقیب‌تان شوید.
