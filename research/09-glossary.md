# ۰۹ — واژه‌نامه: هر کوچه‌ای که در این پرونده استفاده شده

> **چرا این فایل وجود دارد:** من در فایل‌های قبلی با واژه‌های قرضی از انگلیسی می‌نوشتم و دو بار باعث سردرگمی شدم: «US» (که هم اولتراسوند است هم آمریکا) و «دوسیه» (که معنی‌اش پرونده‌ی تحقیقاتی است). هر دو در ۲۰۲۶-۱۰-۰۱ اصلاح شدند: **۵۸ مورد «US» به «اولتراسوند» تغییر کرد** و «دوسیه» به «پرونده‌ی تحقیقاتی».
>
> **قرارداد نگارشی از این به بعد در تمام فایل‌های این پرونده:**
>
> | ❌ ننویسید | ✅ بنویسید |
> |---|---|
> | US (به‌تنهایی) | **اولتراسوند** |
> | US (برای کشور) | **آمریکا** یا **ایالات متحده** |
> | US (در کد حوزه‌ی ثبت اختراع) | فقط داخل فهرست‌های حقوقی مثل `EP/US/WO` و شماره‌ی اختراع مثل `US11883118B2` — این‌ها قرارداد بین‌المللی‌اند و دست‌نخورده می‌مانند |
> | دوسیه | **پرونده‌ی تحقیقاتی** |
> | HFUS | **اولتراسوند فرکانس‌بالا** |
> | POCUS | **اولتراسوند بر بالین بیمار** |

## ۱. تصویربرداری و فیزیک

| کوچه | شکل کامل | معنی به فارسی ساده |
|---|---|---|
| **اولتراسوند / US / Sonography** | Ultrasound / Ultrasonography | تصویربرداری با امواج صوتی بالای ۲۰ کیلوهرتز. **«سونوگرافی» و «اولتراسوند» یک چیزند** |
| **HFUS** | High-Frequency Ultrasound | اولتراسوند فرکانس‌بالا (معمولاً بالای ۱۰ مگاهرتز) — رزولوشن بهتر، عمق کمتر |
| **POCUS** | Point-of-Care Ultrasound | اولتراسوند کنار بیمار، در کلینیک، نه در بخش رادیولوژی |
| **MHz** | Megahertz | مگاهرتز — واحد فرکانس. هرچه بالاتر، تصویر دقیق‌تر و عمق کمتر |
| **B-mode** | Brightness mode | تصویر خاکستری معمولی آناتومی (لایه‌ها: درم، چربی، عضله، فاسیا) |
| **M-mode** | Motion mode | نمایش حرکت در یک خط، در طول زمان |
| **Color Doppler** | — | داپلر رنگی: جهت و وجود جریان خون |
| **Power Doppler** | — | داپلر توانی: حساس‌تر برای جریان‌های کند و رگ‌های ریز، ولی بدون اطلاعات جهت. **برای رگ‌های ۰٫۸ میلی‌متری صورت حیاتی است** |
| **PW Doppler** | Pulsed-Wave Doppler | داپلر موج پالسی: اندازه‌گیری سرعت جریان در یک نقطه‌ی مشخص |
| **RF** | Radio Frequency data | **داده‌ی خام سیگنال** اولتراسوند، قبل از تبدیل به تصویر. برای تحقیق ارزشمند است |
| **IQ data** | In-phase / Quadrature | داده‌ی میانی پردازش سیگنال، قبل از ساخت تصویر خاکستری |
| **envelope** | — | پوش سیگنال؛ مرحله‌ی بعد از IQ |
| **FOV** | Field of View | **میدان دید** — پهناي ناحیه‌ای که یک فریم نشان می‌دهد. برای Clarius L20 HD3 = **۲۵ میلی‌متر** |
| **عمق (Depth)** | — | حداکثر فاصله‌ای که دستگاه می‌بیند. L20 HD3 = ۴ سانتی‌متر |
| **MRI** | Magnetic Resonance Imaging | تصویربرداری تشدید مغناطیسی — بدون اشعه، گران، زمان‌بر |
| **CT** | Computed Tomography | سی‌تی‌اسکن — با اشعه‌ی ایکس |
| **CTA** | CT Angiography | سی‌تی‌اسکن رگ‌ها با ماده‌ی حاجب |
| **DICOM** | Digital Imaging and Communications in Medicine | استاندارد جهانی فایل و انتقال تصویر پزشکی |
| **فانتوم** | Phantom | ماکت آزمایشگاهی بافت/رگ برای تست دستگاه، با ابعاد معلوم (**ground truth**) |
| **ground truth** | — | حقیقت مرجع؛ چیزی که واقعاً هست و مدل را با آن مقایسه می‌کنند |

## ۲. هوش مصنوعی و سنجه‌های دقت

| کوچه | شکل کامل | معنی به فارسی ساده |
|---|---|---|
| **AI** | Artificial Intelligence | هوش مصنوعی |
| **CV** | Computer Vision | بینایی ماشین |
| **سگمنتیشن** | Segmentation | جدا کردن مرز دقیق یک ساختار در تصویر (مثلاً مرز رگ) |
| **Dice** | Dice Similarity Coefficient | **معیار همپوشانی دو ناحیه، از ۰ تا ۱.** مهم‌ترین عدد این پروژه. ۱ = کامل، ۰٫۶ = متوسط، زیر ۰٫۵ = عملاً بی‌فایده |
| **IoU** | Intersection over Union | معیار همپوشانی دیگر، سخت‌گیرانه‌تر از Dice |
| **ASSD** | Average Symmetric Surface Distance | میانگین فاصله‌ی مرز پیش‌بینی‌شده تا مرز واقعی، به میلی‌متر |
| **ACC** | Accuracy | دقت کلی — ⚠️ **برای سگمنتیشن معنای فنی ندارد**؛ باید Dice/sensitivity/specificity گزارش شود. این یکی از ایرادهای دک شماست |
| **sensitivity / specificity** | حساسیت / ویژگی | نرخ پیدا کردن درستِ مثبت‌ها / درست رد کردنِ منفی‌ها |
| **nnU-Net** | no-new-Net | یک چارچوب شبکه‌ی عصبی که خودش را برای داده‌ی شما تنظیم می‌کند؛ **استاندارد فعلی پژوهش سگمنتیشن پزشکی** |
| **Marching Cubes** | — | یک **الگوریتم مش‌سازی سه‌بعدی** از داده‌ی حجمی. ⚠️ منبع دقت نیست؛ دک شما آن را اشتباهاً منبع دقت معرفی کرده |
| **weak label / noisy label** | برچسب ضعیف/پرخطا | برچسبی که ارزان و نیمه‌خودکار ساخته شده و دقیق نیست؛ برای شروع آموزش مدل |
| **overfitting** | بیش‌برازش | مدل داده‌ی تمرین را حفظ می‌کند ولی روی داده‌ی جدید خراب می‌شود |
| **held-out set** | مجموعه‌ی نگه‌داشته‌شده | داده‌ای که مدل هرگز ندیده و فقط برای تست نهایی استفاده می‌شود |
| **MONAI** | Medical Open Network for AI | کتابخانه‌ی بازِ تخصصی برای AI پزشکی |
| **FAST** | Framework for Heterogeneous Medical Image Computing | فریم‌ورک نروژی پردازش بلادرنگ تصویر پزشکی؛ **ماژول آماده‌ی Clarius دارد** |
| **3D Slicer / SlicerIGT / PLUS** | — | نرم‌افزارهای باز استاندارد پژوهشی برای کالیبراسیون پروب، ثبت، و ناوبری |

| **LiDAR** | Light Detection and Ranging | لیزر اسکن عمق (در iPhone Pro و iPad Pro) |

| **registration** | ثبت / هم‌ترازی | انداختن تصویر روی آناتومی واقعی بیمار در جای درست |
| **TRE** | Target Registration Error | خطای ثبت در نقطه‌ی هدف — **مهم‌ترین عدد دقت در ناوبری جراحی** |
| **FID / IFRE** | Fiducial / Initial Fiducial Registration Error | خطای ثبت بر اساس نقاط نشانگر |
| **EM tracking** | Electromagnetic tracking | ردیابی با میدان مغناطیسی (مثل NDI Aurora) — بدون نیاز به خط دید، ولی حساس به فلز |
| **optical tracking** | — | ردیابی نوری (مثل NDI Polaris) — دقیق، ولی باید خط دید باز باشد |
| **latency** | تأخیر | فاصله‌ی زمانی بین حرکت واقعی و نمایش آن |

## ۸. بالینی و آناتومی

| کوچه | شکل کامل | معنی به فارسی ساده |
|---|---|---|
| **HA** | Hyaluronic Acid | هیالورونیک اسید — ماده‌ی اصلی فیلر |
| **CaHA** | Calcium Hydroxylapatite | کلسیم هیدروکسی‌آپاتیت — نوع دیگر فیلر (Radiesse) |
| **NLF** | Nasolabial Fold | **شیار بینی-لبی** = «خط خنده» — یکی از پرتکرارترین نواحی تزریق |
| **SMAS** | Superficial Musculo-Aponeurotic System | لایه‌ی عضلانی-اپونورتیک سطحی صورت |
| **VO** | Vascular Occlusion | **انسداد عروقی** — خطرناک‌ترین عارضه‌ی فیلر |
| **necrosis** | نکروز | مرگ بافت |
| **hyaluronidase** | هیالورونیداز | آنزیم حل‌کننده‌ی فیلر هیالورونیک — پادزهر انسداد عروقی |
| **perforator** | شریان سوراخ‌کننده | شاخه‌های ریزی که از عمق به سطح می‌آیند؛ **عامل بیشتر عارضه‌ها و سخت‌ترین بخش برای دیدن با داپلر** |
| **supratrochlear / supraorbital** | شریان‌های بالای چشم | در ناحیه‌ی گلابلا (بین دو ابرو) |
| **facial artery** | شریان فاسیال | در NLF و کنار بینی |
| **glabella** | گلابلا | ناحیه‌ی بین دو ابرو |
| **radix / rhinion** | ریشه‌ی بینی / نقطه‌ی نوکی بینی | نقاط آناتومیک روی بینی |
| **OR** | Odds Ratio | نسبت شانس — در مطالعه‌ی JAAD 2025 برابر **۵٫۷۷** بود |
| **RRR** | Relative Risk Reduction | کاهش نسبی خطر |
| **surrogate endpoint** | معیار جایگزین | وقتی نتیجه‌ی اصلی خیلی نادر است، یک نتیجه‌ی قابل اندازه‌گیری را جایگزین می‌کنند. برای ما: **کبودی** به‌جای **کوری** |
| **RCT** | Randomized Controlled Trial | کارآزمایی تصادفی‌شده‌ی کنترل‌شده |
| **power** | توان آماری | احتمال اینکه مطالعه اثر واقعی را پیدا کند |
